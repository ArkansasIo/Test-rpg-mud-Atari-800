# RPGMUD MMORPG Systems

This is a text-first MMORPG. Every system is authoritative on the server and exposed through commands and structured text events.

## 1 Character
- account, character slots, identity
- level, XP, rested XP
- attributes, derived stats, resistances
- classes, subclasses, roles
- skills, abilities, spells, cooldowns
- talents, builds, loadouts
- titles, achievements, reputation
- death, recovery, resurrection
- alignment and faction standing

## 2 Items and progression
- equipment slots
- rarity and quality
- item level
- affixes and sockets
- set bonuses
- durability
- upgrades and enchanting
- consumables
- quest items
- bind/equip/trade rules

## 3 Combat
- PvE and optional PvP
- threat/aggro
- party roles
- damage types
- mitigation
- critical hits
- status effects
- crowd control
- interrupts
- healing
- resource systems
- combat states
- loot ownership

- NPCs and schedules
- vendors

- public events

- raid instances
- checkpoints and respawn

- daily/weekly objectives
- achievements

- dungeon and raid progression
