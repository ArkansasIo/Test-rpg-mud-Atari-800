# Original Fantasy MMORPG

Working codename: **Aetherfall Online**.

This is an original text-first MMORPG inspired by the breadth of classic MMORPG design, with original terminology, lore, classes, regions, items, factions, quests, and systems.

The Atari 800 client remains a compact 6502 text client. RPGMUD-64 is the authoritative 64-bit virtual server environment.

Core pillars:
1. persistent character progression
2. large persistent fantasy world
3. cooperative parties and guilds
4. PvE dungeons and raids
5. optional PvP
6. crafting and player economy
7. social and communication systems
8. seasonal and live world events
