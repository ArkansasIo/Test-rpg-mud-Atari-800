# Aetherfall World Design

## World hierarchy
Realm -> Continent -> Region -> Zone -> Room -> Instance.

## Original regions
- The Emberreach
- Moonveil Marches
- Crown of Thorns
- Verdant Expanse
- Ashen Deep
- Stormglass Coast
- Hollow Meridian
- Starfall Basin

## World features
Each zone may contain towns, wilderness, dungeons, quest hubs, resource nodes, rare encounters, faction locations, world bosses, and dynamic events.
