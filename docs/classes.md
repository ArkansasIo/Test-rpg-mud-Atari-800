# Original Classes

Initial class families:
- Vanguard — armored frontline
- Spellweaver — arcane damage/control
- Dawnwarden — healing/protection
- Wildstalker — ranged/scouting
- Nightblade — stealth/melee
- Runeforge — weaponized crafting and elemental combat
- Spiritbinder — summons and spirit magic
- Stormcaller — elemental ranged combat

Classes may branch into original subclasses. Class names and abilities are project-original.
