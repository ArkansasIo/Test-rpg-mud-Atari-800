# MMORPG Content Model

Content is data-driven where practical.

Records:
- characters
- classes
- skills
- spells
- items
- recipes
- quests
- NPCs
- rooms
- zones
- factions
- vendors
- dungeons
- raids
- encounters
- loot tables
- achievements
- guilds
- events
- market listings

The assembly runtime consumes compact serialized records.
