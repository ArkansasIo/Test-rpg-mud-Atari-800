# Aetherfall Online MMORPG Layer

Aetherfall Online is the original fantasy MMORPG layer for RPGMUD.

It intentionally preserves the text-MUD model:
- commands are text
- world state is server authoritative
- clients render text and structured terminal panels
- Atari 800 support remains 6502 assembly
- RPGMUD-64 hosts the scalable server runtime

The project uses original names, lore, mechanics and assets rather than copying proprietary World of Warcraft content.
